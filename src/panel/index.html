数据与安全

API Key 与账号令牌以 0600 权限保存在 ~/.workbuddy-gateway， 不修改 WorkBuddy 桌面端的认证文件。

账号失败只记录原因，不冷却、不封锁； 选号时把刚失败的号排在健康号后面，坏号不会拖慢每次请求。

添加账号

粘贴账号池导出的 JSON。支持数组、{accounts:[…]}、或单个 auth 文档，可一次导入多个。
